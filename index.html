로그인·동기화

Google·Kakao 또는 이메일로 로그인해 같은 계정의 준비 데이터를 다른 기기와 맞춥니다.

직접 등록과 일괄등록

직접 등록

새로운 여행을 단계별로 만들고 필요한 내용을 하나씩 입력할 때 사용합니다.

일괄등록

과거 여행이나 일정이 많을 때 표 붙여넣기 또는 CSV 업로드로 한 번에 등록합니다.

개인 일정과 그룹 일정

개인 일정

내 여행 준비 데이터에 저장하는 교통 또는 숙소입니다. 개인 교통을 저장하는 것만으로 그룹 화면에 자동 공개되지는 않습니다.

그룹 일정

그룹코드로 같은 그룹을 불러와 함께 확인하는 교통 또는 숙소입니다. 개인 교통은 ‘현재 그룹에 공유’를 눌렀을 때 별도 그룹 일정으로 저장됩니다.

그룹 숙소는 참여자별 숙소를 복제하지 않고 하나의 그룹 숙소와 참여자 목록으로 저장됩니다. 같은 그룹코드를 연결하면 공유된 교통과 숙소를 불러오며, 그룹 숙소의 참여자는 각자 설정된 투숙 기간으로 표시됩니다. 그룹코드는 그룹 일정 조회·공유에 필요하고, 계정 로그인은 개인 준비 데이터를 기기 간 동기화할 때 사용합니다.

여행 데이터 가져오기 안내

  • 표 붙여넣기 또는 CSV 업로드를 지원합니다.
  • 한 행에 데이터 하나를 입력하고 참여자는 쉼표로 구분합니다.
  • 국가코드는 JP, HK, US 같은 2자리 코드를 사용합니다.
  • 통화는 JPY, HKD, USD 같은 3자리 코드를 사용합니다.
  • 여행, 페스티벌, 교통, 숙소, 짐싸기를 등록할 수 있습니다.
  • 기존 여행과 연결하거나 여행·페스티벌 행으로 새 여행을 만들 수 있습니다.

저장 및 동기화

로그인하지 않은 데이터는 현재 브라우저의 로컬 저장소에 저장됩니다. Google·Kakao 또는 이메일로 로그인하면 같은 계정의 기기에서 준비 데이터를 불러오고 저장할 수 있습니다. 최초 로그인 때는 기기 데이터를 백업한 뒤 계정 데이터와 합치며, ‘지금 동기화’는 서버와 현재 데이터를 즉시 맞춥니다.

그룹코드는 일행이 공유한 교통·숙소를 불러오는 용도이고 로그인 동기화와는 별개입니다. 데이터 초기화는 화면에 안내된 여행 일정, 숙소, 준비도, 짐싸기, 환전과 비용 데이터를 초기 상태로 되돌립니다. 로그인 중 초기화하면 그 상태도 계정 데이터에 동기화됩니다.

FAQ

처음에는 무엇부터 등록해야 하나요?

새 여행 만들기에서 여행명과 행사·여행 기간을 먼저 등록한 뒤 교통, 숙소와 준비물을 채워보세요.

직접 등록과 일괄등록 중 무엇을 사용해야 하나요?

한두 개 여행은 직접 등록이 간단합니다. 과거 기록이나 여러 일정이 있다면 표 또는 CSV 일괄등록이 빠릅니다.

개인 일정과 그룹 일정은 무엇이 다른가요?

개인 일정은 내 준비 데이터에 저장되고, 그룹 일정은 그룹코드로 연결된 공유 데이터입니다. 개인 교통은 공유 버튼을 눌러야 그룹에 별도로 등록됩니다.

로그인하지 않아도 데이터가 저장되나요?

네. 현재 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 자동으로 이어지지 않습니다.

다른 기기에서도 같은 데이터를 볼 수 있나요?

같은 라이브행 계정으로 로그인하고 동기화하면 개인 준비 데이터를 다른 기기에서 불러올 수 있습니다. 그룹 일정은 해당 그룹코드도 연결해야 합니다.

일괄등록한 내용도 나중에 수정할 수 있나요?

등록 후 각 여행 화면의 기존 관리 기능을 사용합니다. 숙소와 준비물은 수정할 수 있고, 수정 버튼이 없는 교통 항목은 삭제 후 다시 등록해야 할 수 있습니다.

여행마다 다른 통화를 사용할 수 있나요?

일괄등록한 여행에는 ISO 통화코드가 함께 저장됩니다. 환전 화면에서는 현재 사용할 기준 통화를 선택해 저장하고 필요할 때 변경합니다.

짐싸기 완료 상태도 저장되나요?

네. 여행별 체크 상태가 현재 브라우저에 저장되고, 로그인한 경우 준비 데이터 동기화 대상에 포함됩니다.

문제가 있거나 의견이 있나요?

오류 신고와 기능 제안을 보내주시면 사이트 개선에 도움이 됩니다.

오류 화면과 발생 상황을 함께 보내주시면 확인에 도움이 됩니다.

1. 처리하는 정보와 목적

로그인과 계정

  • 이메일 링크 로그인: 이메일 주소, Supabase 사용자 ID, 로그인 시각과 인증 제공자 정보
  • Google·Kakao 로그인: 해당 제공자가 Supabase 인증에 전달하는 이메일, 프로필 메타데이터, 제공자 식별 정보

계정 확인, 로그인 유지, 최근 로그인 방식 표시와 사용자별 데이터 연결에 사용합니다. Google·Kakao에서 실제 제공되는 항목은 사용자의 제공자 동의 범위에 따라 달라질 수 있습니다.

여행 데이터와 동기화

여행, 교통, 숙소, 짐싸기, 준비도, 환전 보유액, 여행비, Festival World Map 기록과 앱 설정을 브라우저 localStorage에 저장합니다. 로그인하면 지원되는 데이터가 Supabase의 사용자 ID에 연결되어 기기 간 동기화됩니다.

그룹 기능

그룹명, 연결 여행, 그룹 설명, 구성원 사용자 ID·역할, 초대 코드와 공유 교통·숙소 일정을 처리합니다. 그룹 구성원만 관련 데이터를 조회하도록 Supabase 접근 정책을 사용합니다.

피드백과 문의

이메일 주소, 문의 유형·제목·내용, 선택 첨부 이미지와 접속 화면, 이전 페이지, 브라우저·언어·화면 및 뷰포트 크기, 온라인 상태, 앱 버전, 로그인 여부와 로그인한 경우 사용자 ID를 처리합니다. 문의 접수, 회신, 오류 확인과 서비스 개선에 사용합니다.

2. 보관과 삭제

  • 브라우저 데이터: 사용자가 해당 브라우저 데이터를 초기화하거나 삭제할 때까지 보관됩니다.
  • 계정·동기화 데이터: 로그인 사용자는 마이페이지에서 직접 계정을 삭제할 수 있습니다. 계정 삭제 시 프로필, 기기 백업과 계정에 연결된 여행·일정·준비물·환전·여행비·설정 및 로그인 상태로 접수한 피드백과 첨부 이미지가 삭제됩니다.
  • 그룹 데이터: 일반 멤버가 탈퇴하면 해당 멤버십만 삭제됩니다. 그룹 생성자가 탈퇴하고 다른 멤버가 있으면 가장 먼저 참여한 멤버에게 그룹과 공유 일정의 관리 권한을 이전해 다른 사용자의 데이터를 유지합니다. 다른 멤버가 없는 그룹만 함께 삭제됩니다.
  • 피드백·첨부 이미지: 로그인하지 않고 접수한 문의는 계정과 연결되지 않으므로 계정 삭제 대상이 아니며, 현재 자동 삭제 기능이 없어 운영자가 수동 삭제할 때까지 보관됩니다.

현재 서비스가 법적 의무에 따라 별도로 보관하는 결제·거래 정보는 없습니다. Google Analytics 4의 집계 데이터는 앱 계정의 사용자 ID나 이메일을 전송하지 않으므로 계정 삭제와 직접 연결해 삭제하지 않습니다.

3. 외부 서비스

  • Supabase: 인증, 사용자별 동기화, 그룹, 피드백 및 첨부 이미지 저장
  • Google·Kakao: 사용자가 선택한 소셜 로그인 인증
  • Resend: 새 피드백의 운영자 이메일 알림
  • Google Analytics 4: 운영 사이트의 페이지·기능 이용 통계. 광고 개인화 신호는 코드에서 비활성화되어 있으며 이벤트에 이름·이메일·예약정보를 전송하지 않습니다.
  • OpenStreetMap·Nominatim: 지도 표시와 사용자가 입력한 행사장·도시 위치 검색

외부 서비스는 각 서비스의 정책과 설정에 따라 정보를 처리할 수 있습니다.

4. 이용자의 선택과 권리

피드백의 필수 개인정보 수집에 동의하지 않을 수 있으나 문의 접수와 회신이 제한됩니다. 브라우저에 저장된 여행 데이터는 마이페이지의 초기화 기능 또는 브라우저 설정으로 삭제할 수 있습니다. 로그인한 사용자는 마이페이지의 계정 관리에서 계정과 연결된 데이터를 직접 삭제할 수 있습니다. 그 밖의 열람·정정 요청은 피드백 보내기를 이용할 수 있습니다.

5. 안전한 이용 안내

피드백과 공개 기록에는 여권번호, 결제정보, 예약번호 등 민감한 정보를 입력하지 마세요. 첨부 이미지는 비공개 저장소에 저장되지만 문의 확인에 필요한 내용만 첨부해 주세요.
